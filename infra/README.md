# infra

Wrangler configuration, DNS records (MX, SPF, DKIM, DMARC), Email Routing setup,
and the account notes needed to reproduce the deployment.

**No secrets.** This directory names them and says where they live. The values
belong to the deployment — see AGENTS.md §5.

The accounts here are this project's own, never Kolonie's
([M-001](../docs/decisions/separate-in-every-account.md)).
